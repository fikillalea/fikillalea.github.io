# Sample Writing Post

_30 March 2026_

Welcome to the sample post on this portfolio site. This post is written in Markdown and is rendered dynamically by `assets/site.js` using `markdown-it`.

You can add more files in `posts/` with:

- `name-post.md`

And include them in the `posts` array in `assets/site.js`.
